# Panduan Praktis Menarik Panah Interaksi (Prototype) di Figma

Seluruh nama layer / section di file `dapoer-pmcsu-laptop-mockup.svg` sudah diberi ID yang jelas dan rapi sehingga sangat cepat ditarik di Figma:

---

### 1. Masuk ke Mode Prototype
1. Buka file Anda di Figma.
2. Di pojok kanan atas layar Figma, klik tab **`Prototype`** (di sebelah tab *Design*).

---

### 2. Tarik Tombol ke Targetnya (Hanya Perlu 1 Klik & Tarik):

| Elemen Yang Diklik | Tarik Panah Biru (+) Ke | Settingan di Panel Kanan |
| :--- | :--- | :--- |
| **"Pilih Menu Sekarang"** (Tombol Emas Hero) | Frame **`Menu-Catalog-Section`** | `On click` ➔ `Scroll to` (Animation: *Ease in and out*) |
| **"Tentang Kami"** (Navbar) | Frame **`Tentang-Kami-Section`** | `On click` ➔ `Scroll to` |
| **"Layanan"** (Navbar) | Frame **`Layanan-Section`** | `On click` ➔ `Scroll to` |
| **"Katalog Menu"** (Navbar) | Frame **`Menu-Catalog-Section`** | `On click` ➔ `Scroll to` |
| **"Galeri Acara"** (Navbar) | Frame **`Galeri-Section`** | `On click` ➔ `Scroll to` |
| **"Panduan Pesan"** (Navbar) | Frame **`Cara-Pesan-Section`** | `On click` ➔ `Scroll to` |
| **"Ulasan"** (Navbar) | Frame **`Testimoni-Section`** | `On click` ➔ `Scroll to` |
| **"FAQ & Area"** (Navbar) | Frame **`FAQ-Section`** | `On click` ➔ `Scroll to` |

---

### 3. Jalankan & Nikmati Prototype
- Klik tombol **Play (▶️)** di pojok kanan paling atas Figma.
- Sekarang semua tombol dan link di navbar ketika dipencet akan otomatis meluncur ke bagiannya masing-masing layaknya website sungguhan!
